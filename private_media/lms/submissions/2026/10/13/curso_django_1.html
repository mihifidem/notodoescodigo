01 · Conoce el curso

Aprende a construir para la web

Un recorrido guiado desde la instalación del framework hasta el desarrollo de aplicaciones completas.

Este curso de Django desde cero está diseñado para todas aquellas personas que desean iniciarse en el desarrollo de aplicaciones web utilizando Python, sin necesidad de tener conocimientos previos sobre este framework.

A lo largo del curso, aprenderás paso a paso los fundamentos de Django, desde su instalación y configuración inicial hasta la creación de aplicaciones web completas, dinámicas y funcionales.

Conocerás la estructura de un proyecto, el funcionamiento de las vistas, las rutas URL, las plantillas HTML y la gestión de bases de datos mediante el ORM de Django.

También aprenderás a trabajar con formularios, realizar operaciones CRUD (crear, consultar, actualizar y eliminar registros), gestionar usuarios e implementar sistemas de autenticación.

El curso combina conceptos teóricos con ejercicios prácticos, permitiéndote aplicar los conocimientos adquiridos y desarrollar buenas prácticas de programación.

Al finalizar, tendrás una base sólida para crear y administrar tus propias aplicaciones web con Django y continuar avanzando en el desarrollo backend con Python.

¿Qué aprenderás?

  • ✓ Proyectos y aplicaciones Django
  • ✓ Vistas, URLs y plantillas HTML
  • ✓ Modelos, bases de datos y ORM
  • ✓ Formularios y operaciones CRUD
  • ✓ Autenticación y gestión de usuarios
  • ✓ Django Admin y buenas prácticas
02 · Metas del aprendizaje

Objetivos del curso

Diez capacidades clave para dominar las bases del desarrollo web con Django.

◎
Objetivo general

Aprender a desarrollar aplicaciones web dinámicas, seguras y funcionales utilizando Django y Python, comprendiendo sus principales herramientas y aplicando los conocimientos adquiridos mediante ejercicios y proyectos prácticos.

01

Comprender los fundamentos de Django

Conocer qué es, cómo funciona y cuáles son sus principales ventajas para el desarrollo web.

02

Instalar y configurar Django

Preparar un entorno de desarrollo y crear proyectos y aplicaciones desde cero.

03

Conocer la arquitectura de Django

Comprender la estructura de los proyectos y el funcionamiento del patrón Modelo-Vista-Plantilla (MVT).

04

Gestionar bases de datos

Crear modelos, realizar migraciones y consultar información utilizando el ORM de Django.

05

Desarrollar páginas web dinámicas

Implementar vistas, configurar rutas URL y utilizar plantillas HTML.

06

Implementar operaciones CRUD

Crear, consultar, actualizar y eliminar registros mediante formularios y vistas.

07

Gestionar usuarios y autenticación

Implementar funcionalidades de registro, inicio y cierre de sesión, así como permisos de acceso.

08

Utilizar el panel de administración

Administrar la información de la aplicación mediante Django Admin.

09

Aplicar buenas prácticas de desarrollo

Organizar el código, reutilizar componentes y utilizar las herramientas de seguridad de Django.

10

Desarrollar un proyecto web completo

Integrar los conocimientos adquiridos para construir una aplicación funcional desde cero.
