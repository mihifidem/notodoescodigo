Instrucciones del Accessible Palette
  1. Elige un color base para iniciar la generación.
  2. Define cuántas paletas quieres generar y cuántos colores máximo tendrán.
  3. Sube una imagen para extraer tonos dominantes automáticamente.
  4. Usa Reset para volver a valores por defecto.
Recomendación: usa paletas pequeñas y contrastadas para interfaces, botones y tarjetas con buena legibilidad.
