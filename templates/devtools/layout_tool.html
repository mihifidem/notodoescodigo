Instrucciones del Layout Calculator
  1. Introduce el número de columnas del grid.
  2. Define el espacio entre columnas (gap).
  3. Indica el ancho del contenedor principal.
  4. La herramienta calcula el ancho real de cada columna.
  5. Usa el botón Reset para volver a los valores por defecto.
Fórmula: ancho_columna = (container - gap × (columns - 1)) / columns
