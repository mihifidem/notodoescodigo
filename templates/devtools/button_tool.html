Instrucciones del Button Generator
  1. Escribe el texto que quieres mostrar en el botón.
  2. Usa el selector de color para definir el fondo y el color del texto.
  3. Ajusta el radio para controlar la redondez de las esquinas.
  4. Configura el padding horizontal y vertical para cambiar el tamaño interno del botón.
  5. Define el ancho y alto para controlar la dimensión final del componente.
  6. Activa la sombra y ajusta sus desplazamientos para dar más profundidad visual al botón.
  7. Haz clic en Generar para ver el resultado en tiempo real.
Consejo: usa contrastes claros entre fondo y texto para mantener el botón legible y accesible.
