Instrucciones del Slugify
  1. Escribe un título, nombre de artículo o una frase larga.
  2. La herramienta convierte letras con acento, espacios y caracteres especiales en una URL limpia.
  3. Usa el slug resultante en rutas, enlaces, SEO o compartir contenido.
  4. Pulsa Reset para borrar el texto y empezar de nuevo.
Ejemplo: “Cómo crear una landing page bonita” → “como-crear-una-landing-page-bonita”
