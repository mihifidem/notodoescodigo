Instrucciones del Color Tool
  1. Selecciona un color con el selector nativo o ajusta el matiz, saturación y brillo.
  2. Explora la rueda cromática para mover el cursor y cambiar el tono de forma visual.
  3. Prueba diferentes armonías: análoga, complementaria, triádica, split, tetrádica o monocromática.
  4. Haz clic en cualquier tono de la paleta para copiar su valor HEX.
  5. Usa “Guardar paleta” para conservar combinaciones favoritas y volver a cargarlas después.
Ejemplos:
#2563EB → azul principal de interfaces
#F59E0B → amarillo de acento
#10B981 → verde de éxito o confirmación
