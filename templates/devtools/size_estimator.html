Cómo usarlo

Calcula un tamaño aproximado de imagen o visual según ancho, alto, escala y densidad. Es útil para estimar archivos, pantallas y recursos antes de entregarlos al diseño o al front-end.

Escala: multiplica el tamaño estimado para simular una versión ampliada o reducida del recurso.
Densidad (DPI): indica la resolución visual del medio: 100-150 dpi suele ser más típico para pantallas, 200-300 dpi para impresión y 300+ dpi para trabajos más detallados o imprenta.
Valores por defecto: ancho 1440, alto 900, escala 1, densidad 200 dpi (2x).

Instrucciones del Size Estimator
  1. Introduce el ancho y el alto de la imagen o pantalla que quieres estimar.
  2. Escala indica cómo se amplía o reduce el recurso; por ejemplo, 1x es tamaño real, 2x lo duplica.
  3. Densidad (DPI) representa la resolución visual del medio: 100-150 dpi suele servir para pantallas, 200-300 dpi para impresión y 300+ dpi para trabajos más detallados o imprenta.
  4. Si un campo queda vacío, la aplicación usa un valor por defecto para evitar errores.
  5. La herramienta te devuelve un tamaño estimado para planificar carga, exportación y rendimiento.
Consejo: si vas a trabajar con imágenes para web, conviene mantener pantallas y activos dentro de tamaños razonables para evitar peso innecesario.
