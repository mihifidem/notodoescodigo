Instrucciones del Spacing Scale
  1. Define la base del sistema de espaciado con un valor como 8, 12 o 16.
  2. La herramienta genera una escala proporcional para margenes, padding y gaps.
  3. Usa valores pequeños para componentes compactos y valores mayores para secciones grandes.
  4. Cuando cambies la base, la escala se recalcula de inmediato y puede aplicarse a tu diseño.
  5. Pulsa Reset para volver a la escala por defecto.
Consejo: una escala consistente reduce la sensación de caos visual y da más orden a la interfaz.
