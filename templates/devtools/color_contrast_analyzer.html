Instrucciones del analizador
  1. Elige un tono para el fondo y otro para el texto con el selector nativo del navegador.
  2. Usa la opción de tamaño para evaluar texto normal o grande según el caso de uso.
  3. Revisa el ratio de contraste y el estado WCAG para saber si cumple AA/AAA.
  4. Prueba una propuesta rápida para comparar combinaciones comunes de interfaz.
Regla rápida: texto normal necesita al menos 4.5:1; texto grande requiere 3:1 para AA, y 7:1 o 4.5:1 para AAA según el tamaño.
