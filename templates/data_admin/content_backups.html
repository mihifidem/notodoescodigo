Cargar copia y restaurar

Selecciona la misma sección que contiene el JSON. Se actualizan las filas con el mismo ID y se insertan las que faltan; no se borran filas adicionales. Las relaciones de etiquetas de las filas restauradas se recuperan desde la copia.

Solo se admiten copias de este formato y esquema, de hasta 10 MB y 10.000 filas. Deben proceder de esta misma instalación: un ID coincidente de otra base podría sobrescribir contenido distinto. Las referencias a usuarios deben existir.

Si algún registro no es válido, se revierte toda la restauración. No se conceden puntos ni se modifica la actividad de usuarios.
