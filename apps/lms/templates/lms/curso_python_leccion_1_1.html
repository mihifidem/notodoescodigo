Lección 1.1 · Nivel principiante

Principios de la programación

Descubre qué significa programar, cómo piensa un ordenador y cuáles son las bases para escribir tus primeros programas en Python.

20 minutos Teoría y práctica Sin conocimientos previos

¿Qué aprenderás?

Al terminar esta lección serás capaz de:

  • Explicar qué es la programación y para qué sirve.
  • Distinguir un algoritmo de un programa.
  • Comprender instrucciones, variables, entrada y salida de datos.
  • Ejecutar una primera instrucción con Python.

1. ¿Qué es la programación?

Programar consiste en escribir instrucciones para que un ordenador realice una tarea. Estas instrucciones deben seguir unas reglas y un orden que el ordenador pueda interpretar o ejecutar.

Por ejemplo, una aplicación que calcula una nota media sigue instrucciones: recibe las notas, las suma, divide el resultado y muestra la respuesta.

Idea clave: un ordenador no adivina lo que queremos: necesita instrucciones precisas y comprensibles.

¿Dónde se utiliza?

La programación está presente en sitios web, videojuegos, aplicaciones móviles, automatización de tareas, análisis de datos e inteligencia artificial.

2. Conceptos fundamentales

Algoritmo

Conjunto ordenado y finito de pasos para resolver un problema.

Programa

Instrucciones escritas en un lenguaje de programación.

Variable

Nombre que permite guardar y utilizar un valor.

Entrada y salida

Datos que recibe un programa y resultados que produce.

Del problema a la solución

  1. Analizar: definir qué queremos resolver.
  2. Diseñar: ordenar los pasos necesarios.
  3. Programar: escribir las instrucciones en Python.
  4. Probar: comprobar el resultado y corregir errores.

3. Tu primer programa en Python

Python es un lenguaje de programación conocido por su sintaxis clara. La función print() permite mostrar información en pantalla.

hola.py
print("¡Hola, mundo!")

Resultado:

¡Hola, mundo!

Usar una variable

saludo.py
nombre = "Ana"
print("Hola,", nombre)

La variable nombre almacena el texto "Ana" y después print() lo muestra. El resultado será Hola, Ana.

4. Ponlo en práctica

Ahora te toca probar. Abre un editor de Python y escribe un programa que:

  1. Guarde tu nombre en una variable llamada nombre.
  2. Muestre un mensaje de bienvenida con print().
  3. Cambie el nombre y ejecute de nuevo el programa.
Reto extra: crea una variable edad y muestra tu nombre y tu edad en dos líneas diferentes.
